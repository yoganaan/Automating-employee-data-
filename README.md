# 🚀 Automating Employee Data Management using ServiceNow

## 📌 Project Overview
This project automates employee data management using ServiceNow. It reduces manual effort, improves accuracy, and ensures efficient workflow handling.

## 🎯 Objectives
- Automate employee record creation
- Reduce manual errors
- Improve data consistency
- Enable approval-based workflow

## 🏗️ System Architecture
User → Form → Validation → Workflow → Database → Output

## 🛠️ Technologies Used
- ServiceNow Developer Instance
- Flow Designer
- Business Rules
- Client Scripts

## ⚙️ Features
- Employee data entry form
- Validation using business rules
- Approval workflow
- Status tracking (Pending, Approved, Rejected)
- Real-time updates

## 🔄 Workflow
1. User enters employee data  
2. Client script validates form  
3. Business rule checks salary  
4. Flow triggers approval  
5. Record updated based on approval  

## 📸 Screenshots
All implementation screenshots are available in the `screenshots` folder.

## 🚀 How to Run
1. Import `UpdateSet.xml`
2. Commit update set
3. Open Employee module
4. Create and test records
